# v0.6.75 BRAT Prerelease

## Purpose

v0.6.75 prevents a no-change focus return from refreshing the current TaskChute view when Obsidian/Vault emits duplicate `create` events for files that already exist or for TaskChute paths unrelated to the visible view.

## Confirmed root cause

The immutable v0.6.74 build treated a path missing from the open-board baseline map as authority to invalidate the current view. On focus return, a burst of `create` events for pre-existing boards and task-definition notes therefore advanced the generation repeatedly and caused a plugin-driven visible refresh.

The faulty equivalence was: missing baseline entry equals known file absence or visible content change. In reality, a missing entry can simply mean that the path is not a dependency of the current rendered view.

## Runtime changes

- Maintain a bounded dependency baseline for currently open TaskChute boards and the task/routine definitions referenced by their rendered rows.
- Represent visible dependencies explicitly as `tracked_present` or `tracked_absent`; a missing map entry means `untracked`.
- Suppress duplicate `create` events when tracked content is unchanged.
- Ignore events for untracked historical/future boards and unrelated task definitions as current-view invalidation authority.
- Preserve one invalidation for tracked-absent dependencies that become present and for genuine tracked content changes, deletes, and relevant renames.
- Refresh the dependency baseline after render, successful visible local or Bridge mutation, manual reload, and open-view/date changes.
- Keep Bridge fetch, apply, persistence, verification, Ack, cursor, and safe-stop semantics unchanged.

## Diagnostics

Existing bounded UI-refresh diagnostics now record:

- event kind and path category
- whether the path is a current visible dependency
- `untracked` / `tracked_present` / `tracked_absent` baseline state
- previous and next stat keys and content fingerprints
- current existence
- classification reason
- generation before and after classification
- whether a refresh was queued

No file content, token, real Vault path, or investigation-only sidecar is recorded.

## Minimal BRAT procedure

1. Install the immutable v0.6.75 assets through BRAT and open TaskChute.
2. Switch to Microsoft Edge for about five minutes without intentionally changing TaskChute data.
3. Return to Obsidian and require zero visible reload, flash, scroll reset, and selection reset.
4. Stop on failure and do not run the backlog test.
5. Only after PASS, create one small pending backlog and require all events to apply/Ack with at most one visible refresh.

Synthetic and static success does not make v0.6.75 Verified. After publication, the tag and three release assets are immutable; any correction requires v0.6.76 or later.
