# v0.6.61 BRAT Prerelease

v0.6.60実Vaultで確認された、`task-insert-below`のvisual順と物理Markdown順が食い違うlatent bugを修正する固定試験配布物です。Verified済み安定版ではありません。

## Changes

- `insertTaskAfterKey()`へ`insertPlacement=explicit-below`を追加します。
- explicitな「下にタスクを追加」と「下にコピー」では、通常targetをtarget指定だけでprotected keyへ加えません。
- 通常targetでは選択行直下へ物理Markdownを保存し、同じanchorへvisual rowを追加します。
- targetが実際にcompleted / running / pausedなら、既存protected block insertionを維持します。
- section top insert、inbound / interrupt continuation、TaskMoved v4、v0.6.60 rename handoffは変更しません。
- order修復のためのTaskMovedは生成しません。
