# v0.6.72 BRAT Prerelease

## Purpose

v0.6.72 removes no-op TaskBoard reloads after idle/focus/resume and coalesces Bridge inbound backlog rendering without changing event apply, verification, Ack, cursor, or safe-stop semantics.

## Runtime changes

- Elapsed idle time is diagnostic context, not UI invalidation authority.
- Focus, visibility return, resume, and first interaction perform a bounded freshness check; no relevant change means zero TaskBoard refreshes.
- Relevant external Vault changes advance a TaskChute data generation. Unrelated notes do not.
- One logical Bridge inbound catch-up owns one UI refresh session across multiple passes and overlapping kickoff reasons.
- Per-event fetch/apply/persist/post-save verification/Ack/cursor ordering remains unchanged.
- Successful visible mutations set session dirty; finalization refreshes an open, visible TaskBoard at most once.
- A safe-stop after a successful prefix may render that prefix once. A stop before mutation renders zero times.
- Closed views are not opened for refresh, and hidden mobile views are not forced to render.
- Final UI refresh errors are diagnostic-only and do not undo applied/Acked events.
- External Vault catch-up waits for late related files and renders once.

## Diagnostics

- refresh session ID and kickoff reasons
- active-session join decision
- idle reason and duration
- pending pass count and visible mutation count
- external invalidation and suppressed refresh count
- final refresh execution/reason or no-refresh reason
- terminal state and bounded UI refresh error

## Targeted BRAT procedure

1. Idle no-change: open TaskChute, leave it untouched for several minutes, then click/touch it. Confirm no flash/reload and no board position reset.
2. Backlog catch-up: leave a target device offline or unopened, create/update several tasks elsewhere, then reopen the target. Confirm all events apply/Ack and the board visibly refreshes at most once after convergence.

The published tag and three BRAT assets are immutable. Any runtime correction requires v0.6.73 or later.
