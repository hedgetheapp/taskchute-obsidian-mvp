# v0.6.58 BRAT Prerelease

実Vault / 実mobile試験のための固定配布物です。synthetic / structural試験は完了していますが、Verified済み安定版ではありません。

## Changes

- inbound server Ackとlocal cursor persistenceを別結果として扱います。
- Ack成功後のcursorを専用trusted persistenceで最新`data.json`へmonotonic mergeします。
- server Ack済みeventはMarkdownへ再適用せず、cursor-only reconciliationでgapを修復します。
- ambiguous Ack responseはbounded retryまたはrecoverable reconciliationへ進みます。
- 401 / 403、identity mismatch、保存後検証失敗等のhard failureとrecoverable cursor failureを分離します。
- mobile rescueはrecoverable Ack / cursor停止をreconcileしてからpending drainを再開します。
- Ack / cursor / device guard / reconcile結果をdiagnosticsで区別できます。
