# v0.6.60 BRAT Prerelease

v0.6.59実Vaultで確認された、空sectionへの最初のtask作成直後renameがBridgeへhandoffされない競合を修正する固定試験配布物です。Verified済み安定版ではありません。

## Changes

- Auto Flushが保持するTaskCreated送信snapshotのevent IDをflush終了までruntimeで追跡します。
- flush対象外のpending / retry可能failed TaskCreatedにはrename後titleとfileをmergeします。
- flush対象中のTaskCreatedにはmergeせず、同じ`task_id + entry_id`のTaskUpdatedを追加します。
- TaskCreatedがoutboxにない既送信相当もTaskUpdatedを追加します。
- pending merge後は既存Auto Flushをwakeします。schedulerのdebounce / min interval / lost wake-up semanticsは変更しません。
- rename handoffのdecisionとTaskUpdated enqueue結果をdiagnosticsへ記録します。
