# v0.6.57 BRAT Prerelease

## Summary

Auto Flush実行中に新しいoutbox eventがenqueueされた際のlost wake-upを修正する、実Vault試験用Prerelease。

## Changes

- flush実行中のauto flush要求をpending wake-upとして保持
- 現在のflush終了後、送信可能なpending eventが残る場合だけ再schedule
- debounceとmin intervalを維持し、同時flush・再帰的な即時flushを回避
- max retry到達済みfailed eventやsuperseded eventだけでは再scheduleしない
- 古いfailed eventがあっても新しい送信可能pending eventを対象にできる既存selectionを維持
- diagnosticsへreschedule requested / executed / not-neededと理由・判定を追加
