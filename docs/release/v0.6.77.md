# v0.6.77 BRAT Prerelease Candidate

## Purpose

v0.6.77 fixes initial mobile TaskChute convergence after a backlog has already been applied, verified, Acked, and persisted to A/B/C.

## Confirmed root cause

`reloadTaskchuteSyncDataFromDisk({ patchViews:false })` advanced `lastRenderedTaskchuteGeneration` without rendering. In addition, an A-only refresh captured an older Markdown snapshot but marked the later global generation current after B/C arrived during its asynchronous read/enrich/render work. Both paths could clear the pending visible mutation without displaying it, so the first board showed A and the second focus recovered A/B/C.

## Runtime changes

- Advance rendered generation only to the exact generation captured immediately before the authoritative Vault Markdown read.
- Do not advance rendered generation for no-render disk reloads, superseded refreshes, failed refreshes, or no-view finalization.
- Retain dirty generation when no eligible view exists.
- On the first eligible visible open, run at most one convergence refresh when dirty remains and no active inbound session owns finalization.
- Record view eligibility, dirty retention, render source, authoritative refresh, and first-open convergence diagnostics.
- Preserve per-event fetch, apply, persist, post-save verify, Ack, and cursor ordering.
